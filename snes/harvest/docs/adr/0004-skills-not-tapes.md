# Harvest is a skill API, not a speedrun tape

The first run is only an intermediate path to credits. Production control must
stay a composable skillset (nav / interact / verify / sequence) that can be
rewritten and later steered by user goals. Frozen input movies are CI and
imitation seeds, not the campaign. Voice-from-microphone is a 2027 stretch;
the seam to leave now is parameterized goals, not STT.
