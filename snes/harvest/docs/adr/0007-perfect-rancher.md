# Perfect is ranch mastery 999 at ending 0x25

The owner asked for this campaign. Perfect means RAM `ranch_mastery` 999 at
ending index `0x25`, from one Clean continuous power-on run. Finish stays the
earlier rung: credits with a score. Perfect is the rung after Finish.

The run is `run_to_day2 --power-on --until-ending`: 0 initial loads, 0 mid-run
loads, 0 RAM writes, and no assists (ADR 0001, ADR 0006). The mastery sum is
index `0x20`; the score is read at the terminal index `0x25`. Every score term
is maxed. Two terms are windows: each girl 496-511 hearts, and each of the
four crops 496-511 shipped. A RAM write or a showcase preset is not this rung.

stamina term at 35, and the natural maximum with every other term at its
table maximum is 984. The best ending at `$83F097` accepts `power_berry_N`
only when it is exactly 10.

   2026-09-28 rule (rollouts in development only, and the final run replayed
   from power-on at 0 loads). The 0-load sentences above are superseded for
   loads only. RAM writes stay forbidden.

   land on 10 berries. The owner did not replace 999 with 984. The missing
   berries are later work, using the edge in item 1.
