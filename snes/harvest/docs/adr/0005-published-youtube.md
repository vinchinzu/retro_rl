# Finish is a 10–20 hour YouTube of the whole game

The completion artifact is a long 60fps emulator-frame recording through the
end of credits, published on YouTube and split into parts as needed, with a
score on the board. A first natural credits run is an intermediate basic path,
not that video, and does not need the ranch-master branch or 999. Live turbo is
a watch knob; it does not shorten the published file to a highlight reel.
