# A hop rewrite is done only when the leave ties to the next room

The next skill must take the new leave cleanly. Pausing in the doorway and
losing a few frames is an allowed Sync cost. If that still fails, the two
rooms are one change, not two beads. Re-pin the next hop. If Red Tower loses
twenty fake jumps and Hellway cannot be joined, the rewrite did not land.
Sync is the flexibility: get back on track. It is not hope, and it is not a
mega-tape to invent the next pin.
