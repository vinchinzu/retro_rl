# One run per check; the milestone run is not a determinism dual

One run proves a hop, a seam, or a tip — not a byte-identical pair. Skills
are RAM-driven; a second run is not a robustness stamp. The A/B loop is two
Skills on one pin. A TAS clock (`settled_gs8`) is a Speed report, not a
second body. Never run twice to prove the emulator is deterministic or to
play the TAS.

A full power-on run to the living tip still gates the major milestones
(Gravity, a new living tip, credits) and every Publish. A 54-minute Phantoon
run on every slop hop would freeze Chip; skipping it when Gravity lands would
make the living tip a lie.

Supersedes the earlier "milestone dual" practice (run every hop rewrite and
every milestone twice and require an exact frame match).
